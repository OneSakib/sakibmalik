# Sakib Malik — Portfolio

A modern personal portfolio website built with [Next.js](https://nextjs.org/), showcasing my projects, skills, experience, and ways to get in touch.

## Features

- Responsive and accessible design
- Project and skills showcase
- About and experience sections
- Contact information and social links
- Fast, SEO-friendly pages powered by Next.js

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm, pnpm, yarn, or bun

### Installation

```bash
git clone <repository-url>
cd sakibmalik
npm install
```

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

```bash
npm run dev      # Start the development server
npm run build    # Create a production build
npm run start    # Start the production server
npm run lint     # Run the linter
```

## Deployment

The site can be deployed to [Vercel](https://vercel.com/) or any platform that supports Next.js applications.
